# Rajneesh Mishra — Portfolio

Personal portfolio site for Rajneesh Mishra, Full Stack Engineer.

## Stack

- React (JavaScript) + Vite
- Tailwind CSS
- Framer Motion
- lucide-react

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Place your PDF at `public/resume.pdf` (a placeholder file is already linked).
